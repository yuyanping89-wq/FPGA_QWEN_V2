# M14 LM Head V2 — Vitis HLS 2021.1 验证

## 结论

Vitis HLS 2021.1（build 3247384）下，CSim、生产尺寸 C synthesis、修复工具包装器后的
6-transaction RTL 仿真、C post-check 和 IP 导出均通过。生产主点积循环
`dot_word_loop` 的 target/achieved II 都是 1；综合明确实例化 8 个 FP32 multiplier 和
8 个 FP32 adder，因此当前并行不是只有单个乘加单元的流水线。

## CSim 与接口合同

- CSim：`LM_HEAD_V2_CSIM=PASS`。
- Python reference：4/4 通过；8-step 资产校验通过。
- 源码合同：33 个顶层参数、34 个 AXI-Lite port，通过。
- 四个 M_AXI bundle：`m_axi_hidden`、`m_axi_weight`、`m_axi_history`、
  `m_axi_logits`，数据宽度 128 bit，地址宽度 64 bit。
- HLS 生成的 AXI-Lite 名称中，hidden 指针为 `hidden_offset`，hidden size 为
  `hidden_size_r`；standalone 驱动直接引用生成头文件，没有复制寄存器偏移常量。

## 生产尺寸 C synthesis

目标器件为 `xczu9eg-ffvb1156-2-i`，目标时钟 10.00 ns。

| 指标 | 2021.1 结果 |
| --- | ---: |
| HLS estimated clock | 8.660 ns（115.47 MHz） |
| `dot_word_loop` tripcount | 112 |
| `dot_word_loop` iteration latency | 9 cycles |
| `dot_word_loop` target / achieved II | 1 / 1 |
| `dot_word_loop` latency | 119 cycles（子模块总 latency 121） |
| 点积进程最大估算 | 23,094,273 cycles，100 MHz 下约 230.94 ms |
| BRAM_18K | 95 |
| DSP | 59 |
| FF | 35,124 |
| LUT | 43,280 |

点积循环子模块使用 40 个 DSP：8 个 FP32 multiplier 各使用 3 个 DSP，8 个 FP32
adder 各使用 2 个 DSP。完整顶层还包含 reduction、penalty、CRC 和控制逻辑，总计
59 个 DSP。

顶层使用 DATAFLOW，生产数据路径由权重读取、点积、partial reduction 和
penalty/argmax 等进程并行运行。II=1 表示稳定状态每周期接收一个 128-bit 权重 beat，
该 beat 内的 8 个 BF16 权重与 8 个 cached hidden 元素同时进入 8 路 FP32 乘加路径。

## RTL CoSim

测试覆盖 6 个事务，包括有效 penalty/argmax、tie、关闭可选 I/O、CRC/计数器和非法
任务。Vitis HLS 2021.1 的标准 `cosim.log` 最终仍记录 FAIL，原因是生成包装器查找
`c.lm_head_v2.autotvin_hidden_size_r.dat`，而同一工具只生成
`c.lm_head_v2.autotvin_hidden_size.dat`。这属于 2021.1 的标量命名不一致，不是 RTL
数值比较失败。

`scripts/run_hls.ps1` 只在原始向量存在、`_r` 向量缺失且标准 CoSim 已失败时复制该
别名，再运行工具生成的完整 `sim.bat`。修复后证据为：

- XSIM 完成 `RTL Simulation : 6 / 6`；
- C 前检查和 C post-check 均输出 `LM_HEAD_V2_CSIM=PASS`；
- 包装脚本最终输出 `LM_HEAD_V2_COSIM_PASS`。

仿真初始化/无效拍出现 DSP48E1 OPMODE warning，但六个事务的逐项 post-check 均通过。
由于修复发生在 HLS 顶层命令返回之后，2021.1 没有生成可信的标准 latency 汇总表；
本报告不从该次 CoSim 推导生产延迟。

## IP 导出

- VLNV：`user.org:llm_fpga:lm_head_v2:2.0`。
- ZIP：`user_org_llm_fpga_lm_head_v2_2_0.zip`。
- 大小：566,639 bytes。
- SHA256：`04ca9c4a2d096a6f3933be3b42ff86ddbf0bf5aff3031db2b00dbd7242a93eda`。
- 四个 M_AXI 的 AWADDR/ARADDR 均为 64 bit。

2021.1 IP Packager 把构建日期编码为超出 32-bit signed range 的 `core_revision`，触发
`bad lexical cast`。导出脚本只在精确匹配该错误时把 revision 改成 Unix seconds
`1790698105` 后重新打包；RTL、接口和寄存器映射没有被修改。

关键原始证据已从可删除的构建树复制到 `reports/hls_2021_1/`，包括顶层和
`dot_word_loop` csynth 报告、`component.xml`、生成寄存器头和精简 CoSim 行号摘要。

## 仍需板上验证

HLS 结果证明计算结构和 RTL 功能，但不能证明 PS DDR 实际带宽、AXI stall、板上 wall
time 或真实 8-step V2 准确度。这些指标需在板卡恢复供电和 JTAG 后按
`BOARD_TEST_PLAN.md` 测量。
